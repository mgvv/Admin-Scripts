# SAP Ariba File Archival & Purge Suite

A suite of production-grade Bash utilities designed to identify, archive into ZIP format, log, and purge historical files modified prior to **January 1, 2026** in SAP environments.

---

## Suite Overview

This repository consists of two scripts designed to separate the **archival/compression stage** from the **file deletion stage** for safety and verification:

1. **`archive_pre_2026.sh`**: Scans the source directory, creates a timestamped `.zip` archive, and generates a `.log` file listing all processed files.
2. **`delete_archived_files.sh`**: Reads the log file generated by the archive script and removes **only** the explicitly listed files from the source directory.

---

## Prerequisites

Ensure the target Unix/Linux environment has the following standard utilities installed:
- `bash` (v4.0+)
- `find`
- `zip` & `unzip`
- `xargs`
- `sed`

---

## Installation & Setup

1. Save both scripts to your system (e.g., under `/usr/sap/int/gp1/tmcc/ariba/dna/arc/`).
2. Make both scripts executable:
   ```bash
   chmod +x archive_pre_2026.sh delete_archived_files.sh
   ```

## 1. Archival Script (`archive_pre_2026.sh`)

### Usage Syntax
```bash
# Archival / Compression
./archive_pre_2026.sh <source_directory> <destination_directory> [--dry-run]

# Revert / Restoration
./archive_pre_2026.sh -r <zip_file_path> <source_directory>
```

### Options & Flags
| Parameter / Flag | Description |
| :--- | :--- |
| `<source_directory>` | Directory containing historical files to evaluate and compress |
| `<destination_directory>` | Target directory where output `.zip` and `.log` files will be saved |
| `-d`, `--dry-run` | Previews files modified prior to 2026 without creating archives or logs |
| `-r`, `--revert` | Restores files from a `.zip` archive back into the source directory |
| `-h`, `--help` | Displays usage instructions |

### Examples

**Dry-Run (Preview files to be archived):**
```bash
./archive_pre_2026.sh /usr/sap/int/gp1/tmcc/ariba/dna/arc /backup/archives --dry-run
```

**Execute Archival:**
```bash
./archive_pre_2026.sh /usr/sap/int/gp1/tmcc/ariba/dna/arc /backup/archives
```
*Generated Output Artifacts:*
- `/backup/archives/archive_pre_2026_20260730_120000.zip`
- `/backup/archives/archive_pre_2026_20260730_120000.log`

**Revert Archive (Unzip back to source):**
```bash
./archive_pre_2026.sh -r /backup/archives/archive_pre_2026_20260730_120000.zip /usr/sap/int/gp1/tmcc/ariba/dna/arc
```

## 2. Deletion Script (`delete_archived_files.sh`)

### Usage Syntax
```bash
./delete_archived_files.sh <log_file_path> <source_directory> [--dry-run]
```

### Options & Flags
| Parameter / Flag | Description |
| :--- | :--- |
| `<log_file_path>` | Full path to the `.log` file generated during archival |
| `<source_directory>` | Directory from which listed files should be deleted |
| `-d`, `--dry-run` | Previews file deletions without performing actual `rm` operations |
| `-h`, `--help` | Displays usage instructions |

### Examples

**Dry-Run Deletion (Verify files before deletion):**
```bash
./delete_archived_files.sh /backup/archives/archive_pre_2026_20260730_120000.log /usr/sap/int/gp1/tmcc/ariba/dna/arc --dry-run
```

**Execute Deletion:**
```bash
./delete_archived_files.sh /backup/archives/archive_pre_2026_20260730_120000.log /usr/sap/int/gp1/tmcc/ariba/dna/arc
```

## Complete End-to-End Workflow Example

Below is the recommended operational workflow for SAP Basis/System Administrators:

1. **Step 1: Preview files eligible for compression**
   ```bash
   ./archive_pre_2026.sh /usr/sap/int/gp1/tmcc/ariba/dna/arc /backup/archives --dry-run
   ```

2. **Step 2: Generate ZIP archive and log file**
   ```bash
   ./archive_pre_2026.sh /usr/sap/int/gp1/tmcc/ariba/dna/arc /backup/archives
   ```

3. **Step 3: Preview deletion from log file**
   ```bash
   ./delete_archived_files.sh /backup/archives/archive_pre_2026_20260730_120000.log /usr/sap/int/gp1/tmcc/ariba/dna/arc --dry-run
   ```

4. **Step 4: Execute targeted deletion**
   ```bash
   ./delete_archived_files.sh /backup/archives/archive_pre_2026_20260730_120000.log /usr/sap/int/gp1/tmcc/ariba/dna/arc
   ```

## Safety Features & Error Handling

- **Log-Driven Precision**: `delete_archived_files.sh` strictly removes only files listed in the specified `.log` file, preventing accidental mass deletion.
- **Path Normalization**: Handles relative `./` paths gracefully using `sed` to avoid missing file errors.
- **Non-Destructive Dry-Run**: Both scripts support `--dry-run` modes to validate path targets prior to execution.
- **Automated Directory Handling**: Missing target directories are automatically created using `mkdir -p`.
